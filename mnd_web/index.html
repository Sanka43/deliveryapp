Admin setup

  1. Enable Email/Password sign-in in Firebase Console → Authentication.
  2. Create an Auth user for the admin email.
  3. In Firestore, create or merge customers/{thatAuthUid} with role: "admin" (and optional displayName).
  4. Deploy mnd_customer/firestore.rules and firestore.indexes.json — required for Shop categories / types (shop_categories, shop_types) and other admin writes: firebase deploy --only firestore
  5. Serve this folder over HTTP (not file://) if the browser blocks Firebase.
  6. Add broad Shop categories (Food, Grocery), then Shop types under each (shop_categories, shop_types with categoryId).
  7. Shop approvals: approve MND Shop vendor registrations (vendors/{uid}).
  8. Job approvals: approve customer app job posts (jobs collection).
  9. Rating Management: moderate customer shop ratings (store_ratings). Vendor rating / ratingCount are recomputed by Cloud Functions.
  10. Rider approvals: approve MND Rider registrations (riders/{uid}).
