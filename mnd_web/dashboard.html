Shop categories

Broad groups for vendors (e.g. Food, Grocery). Firestore shop_categories: label, order, active, isGrocery. The Grocery checkbox is what the shop app uses to decide whether new vendors under this category get the grocery product form (aisle picker, pack pricing, stock) instead of the food form — set this explicitly rather than relying on the label text, so renaming a category can't silently misclassify new vendors.

Admin setup

  1. Enable Email/Password sign-in in Firebase Console → Authentication.
  2. Create an Auth user for the admin email.
  3. In Firestore, create or merge customers/{thatAuthUid} with role: "admin" (and optional displayName).
  4. Deploy mnd_customer/firestore.rules and firestore.indexes.json — required for Shop categories / types / grocery aisles (shop_categories, shop_types, grocery_aisles) and other admin writes: firebase deploy --only firestore
  5. Serve this folder over HTTP (not file://) if the browser blocks Firebase.
  6. Add broad Shop categories (Food, Grocery), then Shop types under each category. Manage Grocery aisles separately for product forms and customer chips. (shop_categories, shop_types with categoryId).
  7. Shop approvals: approve MND Shop vendor registrations (vendors/{uid}).
  8. Job approvals: approve customer app job posts (jobs collection).
  9. Ride fares: set Bike / Wheel / Car quote rates (ride_fare_config/rates).
  10. Rating Management: moderate customer shop ratings (store_ratings). Vendor rating / ratingCount are recomputed by Cloud Functions.
  11. Rider approvals: approve MND Rider registrations (riders/{uid}).
